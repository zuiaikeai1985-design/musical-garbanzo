# 《人间注》思路优化稿 2.0

**本稿性质：** 对《人间注》创意思路的一次系统升级——不推翻，只补强
**优化依据：** 三稿推演（思路稿 → 产品融合稿 → 心灯计划商业稿）之后回望，原思路有四处需要加固
**一句话概括：** 1.0 解决了「为什么动人」，2.0 解决「为什么走得通」。

---

## 0. 先说清楚：哪四处要补强

| # | 1.0 的薄弱点 | 2.0 的解法 |
| --- | --- | --- |
| 一 | 「九人接力」是唯一路径——现实中漂流类项目断流率极高，机制太脆 | **九世多轨**：接力之外增加家传、共写、驻店三轨 |
| 二 | 纯结缘「永不售卖」与《心灯计划》第一轮发售存在产品接口缺口 | **一书两版**：自留本（卖）× 漂流本（捐），买一捐一天然打通 |
| 三 | 「32 问是内容心脏」说了三稿，一直没拟出来 | **本稿直接交付 32 问全稿初稿**（四辑 × 八问） |
| 四 | 扫码之后看到什么、隐私怎么保、坏内容怎么防——体验与安全没走通 | **60 秒体验流 + 笔名制 + 三层审核** |

## 1. 优化一：一书两版（打通公益与生意的接口)

同一本《人间注》，两个版本，内容完全一样（32 问 + 三行白话 + 留白），只在**流转设计**上分岔：

| | 自留本 ·「我注」 | 漂流本 ·「人间注」 |
| --- | --- | --- |
| 怎么来 | 零售发售（心灯计划第一轮） | 只能捐出或受赠，**永不售卖** |
| 给谁写 | 自己写满 32 问——「我与自己的九个月」 | 九世流转——「我与人间的善意」 |
| 封面区别 | 纯黑金 | 多一圈九世珠环 + 流转编号 |
| 内页区别 | 无珠位 | 九个珠位 + 传灯帖 |
| 数字端 | 个人档案 + 注卡 | 本子档案 + 九世地图 |

两版之间的三个通道，让生意和公益互相供血：

1. **买一捐一**：每卖出一本自留本，品牌以买家名义捐出一本漂流本——买「我注」，点亮一本「人间注」。
2. **转世通道**：自留本写满后，主人可一键登记「转世」——这本私人笔记升格为漂流本传出去，主人自动成为第一世。**私人的答案变成公共的善意，这是全案最动人的升维动作。**
3. **归家通道**：漂流本走完九世归档后，第九世收藏人可请购一本自留本「续写」——公益反哺零售，闭环成环。

## 2. 优化二：九世多轨（把断流率从风险变成产品）

「九」不变，「怎么走完九世」放开。四条轨，覆盖四种真实的人际结构：

| 轨 | 走法 | 九世的含义 | 适配场景 |
| --- | --- | --- | --- |
| **接力轨**（原设计） | 九个人依次传递，一人一世 | 九个陌生或半熟的人 | 社群、同事、朋友链 |
| **家传轨**（新增） | 一家人共写一本，节日生日各写一笔 | 一家三代、九次落笔 | 过年、寿宴、家庭仪式——「传家本」 |
| **共写轨**（新增） | 一个集体共持一本，成员轮流作注 | 九位共写者代表 | 班级、病房、车间、创业团队 |
| **驻店轨**（新增） | 本子驻留在一个场所，路过的人写一句 | 九位路人写满即归档 | 咖啡馆、民宿、候诊室、理发店——「驻店本」 |

四轨统一规则：都以「九」为归档刻度，珠印、扫码、长卷机制完全通用。

**为什么这一步重要：** 接力轨考验人的主动性（最容易断），家传轨绑在亲情上（几乎不断），共写轨绑在组织上（有人管），驻店轨绑在空间上（不会丢）。**四轨并行后，断流从「系统性风险」降级为「接力轨的局部损耗」**——原有的接本池、断点复活机制继续作为兜底。

驻店轨另有一个隐藏收益：每个驻店点就是一个线下传播位。一家咖啡馆的桌上放着一本写了六世的《人间注》，比任何广告都让人想翻开。

## 3. 优化三：32 问全稿（初稿，供内容组打磨）

四辑对应人生四件事：**安（心往哪放）、放（执念怎么放）、舍（得失怎么算）、观（人生怎么看）**。每问锚定《金刚经》一分的主题，全部口语化、零宗教术语、人人可答。

### 第一辑 · 安——心往哪放（第一至八分）

| 分 | 经文锚点 | 人生之问 |
| --- | --- | --- |
| 一 · 法会因由 | 着衣持钵，饭食讫 | 你有多久，没有好好吃一顿饭了？ |
| 二 · 善现启请 | 应云何住，云何降伏其心 | **心慌的时候，把心放在哪？**（全案主问） |
| 三 · 大乘正宗 | 度众生而无度者 | 你有没有默默帮过一个人，从没说出去？ |
| 四 · 妙行无住 | 不住相布施 | 你上一次不求回报地付出，是什么时候？ |
| 五 · 如理实见 | 凡所有相，皆是虚妄 | 你有没有被一个「人设」困住过？ |
| 六 · 正信希有 | 生实信者 | 你还相信「好人有好报」吗？ |
| 七 · 无得无说 | 无有定法 | 有没有一句道理，你年轻时深信，现在放下了？ |
| 八 · 依法出生 | 福德即非福德性 | 你觉得自己是个有福气的人吗？ |

**使用说明：**
- 第二问是全案「主问」（与心灯计划播传句同源），印在封面拉页与所有传播物料上；
- 四辑名（安 · 放 · 舍 · 观）即目录，也是视频课的四个季播单元名；
- 本稿为初稿，建议内容组按「口语度 / 扎心度 / 可答度」三维打分打磨，并请译本作者核校每问与经文的锚定关系。

## 4. 优化四：扫码之后的 60 秒（数字体验流）

页角珠印码扫开后，一屏到底，四段式：

```
0–10 秒   这一分的完整译文（你已做好的译本，按分拆条）
10–30 秒  这一问的 3 分钟视频课（小鹅通切片，可静音字幕看完）
30–50 秒  「别人怎么答」——漂流本显示本册前几世注解；
          自留本显示全国精选注解（脱敏笔名展示）
50–60 秒  输入框：「这一问，你的日子怎么答。」
          写下即存入个人档案 → 可一键生成注卡（社交货币）
```

三条体验铁律：

1. **全程零购买入口**（红线延续）——纵深给足，生意在别处；
2. **先给再要**：先给译文、课、别人的答案，最后才请你写——顺序不可颠倒；
3. **写完必有回响**：提交后 24 小时内必收到一条回执（「你的注解已入长卷第 ×× 行」）——**被郑重对待，是用户写第二句的全部理由。**

### 隐私与内容安全（补 1.0 的缺）

- **笔名制**：所有注解以自取笔名流转与展示，真名只存于捐赠 / 权益系统；
- **三层审核**：机审敏感词 → 人工抽审 → 社群志愿者（金刚兄弟）巡查认领；
- **实体页风险**：漂流本扉页印一行小字「本册注解将被后来者读到，请像给陌生人写信一样落笔」——**提示语本身就是审核的第一道闸**；发现不当内容的接本人可扫码报告，该页由品牌回收换新页（原页归档不销毁，保全流转完整性）。

## 5. 优化五：受赠场景优先级（书库地图）

「迷茫中的人」要落到具体的地方。按「心慌浓度」排序：

| 优先级 | 场景类型 | 具体点位 | 适配轨 |
| --- | --- | --- | --- |
| 一 · 等待的地方 | 慌在悬而未决 | 肿瘤科家属等候区、ICU 门外、高考教室、法院调解室 | 驻店轨 / 共写轨 |
| 二 · 重启的地方 | 慌在从头再来 | 戒毒所、监狱图书角、再就业帮扶中心 | 共写轨 |
| 三 · 漂着的地方 | 慌在无根 | 工地书屋、城中村公寓驿站、货运司机之家 | 驻店轨 / 接力轨 |
| 四 · 送别的地方 | 慌在离别 | 临终关怀病房、宠物医院告别室 | 驻店轨 |

**运营要点：** 每个受赠点挂一块小铜牌「此处有一盏灯 · 心灯书库第 ××× 号」——受赠点本身进入心灯地图，捐赠人看得见自己的书驻在哪里。

## 7. 收束

> 1.0 说：送一本只写了一半的书。
> 2.0 说：**这本书有两个命——一个陪你写完自己，一个替你走进人间。**
> 买的那本叫「我注」，捐的那本叫「人间注」；
> 写满的可以转世，走完的可以归家——
> 书在人间转，灯在地图亮，心在长卷里，一年年攒下去。
