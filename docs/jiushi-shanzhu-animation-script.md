# 《九世一念》动画脚本

九世善珠品牌动画 · 新国风珠宝短片

**成片时长：** 75 秒（正片） / 30 秒（社媒减切） / 15 秒（产品钩子）  
**画幅：** 1920×1080，30 fps  
**Remotion 合成：** `JiushiShanzhu`

---

## 1. 作品定位

一颗善珠穿越九世，始终落回母亲掌心。

本片不是卖货片，是品牌起源神话。它把九世善珠的四个核心——**孝、缘、五行、善珠**——收进一条可被记住的句子：

> 一念为善，一珠为念。九世流转，不改初心。

叙事语气靠近上海美影的水墨诗意，气质靠近当代国风珠宝大片：慢、净、金、暖。不讲复杂剧情，只让同一颗珠在九个时代里换一双手，而那双手最终都是母亲的。

## 2. 风格宪章

### 视觉

| 维度 | 规定 |
| --- | --- |
| 底色 | 墨黑 `#070604`，宣纸金 `#F4E6C8` |
| 主光 | 金箔 `#D4B45A` / 亮金 `#F0D78A` |
| 辅色 | 朱砂（火）、碧玉（木）、水色（水）、暮土（土）、冷金（金） |
| 线条 | 细金线，空心描边，少填满 |
| 运动 | 缓入缓出，呼吸感缩放 1.00–1.06，禁止快切炫技 |
| 质感 | 胶片颗粒 + 暗角 + 金尘，像旧绢本被灯照亮 |
| 字体 | 标题用稚拙书体（ZCOOL 小薇 / 马善政），旁白用宋体 |

禁止出现卡通夸张表情、霓虹赛博、电商大字报、产品参数清单。珠永远比人更清楚，人只以掌、发、伞、信、灯暗示。

### 听觉

- 主乐器：古琴，留大量空白。
- 低音：极轻的心跳或木鱼，每 9 拍一次。
- 过门：每一世换一声物件——露落、玉碰、驼铃、绣针、雨、门环、潮、日光灯、金碰。
- 旁白：女声，40 岁左右，近耳，不煽情。每句说完必须停一拍。

### 叙事

九世不是编年史课，是同一份母爱的九次化身。每世只给一个字、一个物、一句旁白。观众应在第 5 世就猜到珠会回家，第 9 世才被允许落泪。

## 4. 完整旁白

**片头**  
一颗善珠，穿越九世，始终落回母亲掌心。

**九世**  
第一世，珠是一滴露。母亲用掌心接住晨光。  
第二世，珠是一粒祭玉。女儿把祈愿系进母亲的衣襟。  
第三世，珠随驼铃西去。它记得故乡灶火的温度。  
第四世，珠作嫁妆。绣线绕过它，绕过一生的叮嘱。  
第五世，珠绾在发间。江南雨落，母女共撑一把伞。  
第六世，珠成信物。离散的夜里，它替人守着回家的路。  
第七世，珠漂向异乡。信封里夹着它，和一句「好好吃饭」。  
第八世，珠传给女儿。车间灯亮着，像母亲没说完的话。  
第九世，珠落回掌心。女儿为母亲戴上，光，圆满了。

**缘**  
缘不是偶然。是九世里，每一次回头。  
百善孝为先。母爱福泽三代。

**片尾（不上口播，只上字幕）**  
九世善珠  
一生一枚 · 守护母亲  
99感恩母亲日 · 每月九日祈福

## 5. 正片分镜（75 秒）

时间码按 00:00–01:15。运镜默认「缓推 / 呼吸缩放」。

- **旁白：** 一颗善珠，穿越九世，始终落回母亲掌心。
- **音：** 琴起一声，珠落有轻叩。

## 7. 制作规格

- **成色：** 偏暖，高光金色不过曝，黑位保住墨底。
- **字幕安全区：** 左右各留 120 px，底部珠轨上方不再叠字。
- **人声响度：** 旁白 -16 LUFS，音乐低于旁白 8 dB。
- **交付：** 1080p 主文件；9:16 竖版需重排（竖排标题改顶栏，九世改为上下结构）。
- **可替换资产：** 品牌书法「缘」、真实珠宝微距、母亲手部实拍。脚本里的线描 Motif 是动画占位，实拍替换时仍保持金线与墨底。
