## 第一部分 · 精髓拆解：五个原理

你说的那句话就是总纲——**「让这个事情变得和所有人有关系」**。往下拆，是五个可以直接口头转述的原理：

### 原理一：把「懂」的门槛降到一句话

- 传统做法：请你读完一本经（哪怕有译文）。读完是门槛，绝大多数人跨不过去。
- 人间注做法：只请你回答一问。「心慌的时候，把心放在哪？」——谁都答得出一句。
- **转述句：我们不要求任何人读懂金刚经，只请他回答一个跟自己有关的问题。答了，他就进来了。**

### 原理二：把「传播」变成「传递」

- 传播是内容从屏幕上飞过去，看完即忘，成本归品牌；
- 传递是实物交到手上——有重量、有编号、有前面几个人的字迹、有「不能断在我手里」的责任感。
- 人对广告的注意力以秒计，对接力棒的珍惜以月计。
- **转述句：广告是飞过去的，本子是递过来的。递过来的东西，人会当真。**

### 原理三：把「用户」变成「作者」

- 他写下的那句注解，会被下一世的人读到，会进入年度注疏长卷，可能在冬至夜被朗读。
- 一个普通人的一句话，获得了「被郑重对待」的待遇——这是比任何礼品都贵重的回报。
- **转述句：我们不是把书送给读者，是把「作者」这个身份送给每个人。**

### 原理四：把「九」用到底

- 九世传珠（品牌）→ 九颗珠（产品）→ 九盏灯（年度计划）→ 九人一本（人间注）→ 九个珠位（本内页）。
- 所有机制共用同一个数字母题：用户不需要学习任何新概念，品牌记忆在每个触点复利。
- **转述句：别人做活动要教育用户，我们的活动用户一看就懂——因为还是那个「九」。**

### 原理五：把「商业」放在旅程最后一站

- 入口永远免费、永远是善意（本子不卖钱）；商业只在终点安静等着（走完的人自然想留个纪念）。
- 善事因此保持干净，生意因此拥有抄不走的护城河——**对手可以抄产品，抄不走用户和这本本子共度的九个月**。
- **转述句：我们不在门口收钱，我们在终点备好纪念品。**

## 第二部分 · 一个人的完整旅程（把机制讲成故事）

> 给内部讲、给合作方讲，用这个故事，比讲十页机制都快。

王姐，46 岁，小学教师。三月，她在社区的一场公益活动上（我们一百场里的一场）接过一本《人间注》，编号 0217——她是这本本子的**第四世**。

扉页上有前三个人各自留下的一句话。第三世是位大学生，写的是：「原来我妈骂我的时候，我也可以不接。」王姐笑了，第一次觉得这本书跟自己有关系。

她翻到第 18 问：**「你有没有被别人的一句话困住过？」** 左页印着一小段原文、三行白话。她想起婆婆去年说的那句话，在右页写下：「困了半年，写下来这一刻，好像放下了一点。」然后在第四个珠位盖上珠印。

睡前她扫了页角那枚小印——手机里跳出这一分的**完整译文**，往下滑，还有一条 4 分钟的**视频课**。她听完，第一次觉得《金刚经》不吓人。接下来两周，她又答了七问，看了七条课。

四月，她把本子亲手交给了闺蜜。闺蜜扫码登记为**第五世**，王姐手机上的珠印亮起第四颗——她看得见这本本子继续往前走：第五世、第六世……第九世是位她不认识的退休医生，本子永远留在了他家书房。

十二月，冬至归一夜。王姐在「人间注疏」长卷里找到了自己那句话，下面有十几个陌生人点了「同感」。那天她给自己订了一串九世善珠，选了**注珠**定制——第九颗珠内侧，刻着「0217 · 第四世」。

**她买珠宝不是因为促销，是因为她想把这段日子戴在手上。**

## 第三部分 · 产品融合总架构：一本 · 一课 · 一珠

### 3.1 融合的钥匙：闻 · 思 · 修

四样资产不是四个货架，而是**一个人与《金刚经》关系的三个深度**。佛家本有「闻、思、修」三学次第，正好一一对应：

```
深度      次第    产品                角色              商业属性
─────────────────────────────────────────────────────────────
遇见  →   闻     《人间注》笔记本     入口 · 善缘        永远免费，只结缘
明白  →   思     译本 + 视频课程      纵深 · 陪读        译文免费，课程轻付费
随身  →   修     九世善珠珠宝         纪念 · 凭证        明码售卖，永不推销
─────────────────────────────────────────────────────────────
                 底座：100 场公益（原点网络）+ 金刚兄弟（人）+ 九灯印（数字机制）
```

- **闻**：一本半白的笔记本，让人「遇到」一问——零门槛，和所有人有关系。
- **思**：想弄明白的人，有路可走——你已做好的译本和视频课，就是这条路。
- **修**：走过一段的人，想把这段日子「戴在身上」——珠宝在终点等他。

**转述句：本子管相遇，课程管相知，珠宝管相守。**

### 3.2 四个产品的角色界定（是什么 / 不是什么）

| 产品 | 是什么 | 不是什么 |
| --- | --- | --- |
| 笔记本《人间注》 | 入口、善事、接力棒 | 不是赠品，不是印刷版译文，**永不售卖** |
| 译本 | 本子的「扩展包」，扫码即达的纵深 | 不是独立出版物首发渠道，不整本塞进本子 |
| 视频课 | 译本的「声音注脚」，一问一课 | 不是网课生意的主力，不设追销话术 |
| 珠宝 | 旅程里程碑的凭证、有编号的纪念 | 不是货架商品的场景促销，**不承诺任何功效** |

### 3.3 四个互嵌机制（融合的具体做法）

融合不是「摆在一起卖」，是**互相成为对方的一部分**：

**① 本中有课**
本子每一分的页角有一枚珠印小码。扫码 = 该分完整译文 + 对应视频课切片。
本子是课程的**纸质目录**，课程是本子的**声音注脚**。看不够的人自然往下走，不想走的人翻页即可——纵深永远在，但从不打扰。

**② 课中有本**
每条视频课的结尾不布置作业、不导购，只有固定的一句话：
「这一问，你的日子怎么答——写在你的本子上。」
课程为本子回流，让「看课的人」变回「写注的人」。**内容的终点是行动，不是完播率。**

**③ 本中有珠**
本子内页的九个珠位，盖满九枚珠印后，**那一页的图案恰好是一串九颗珠**——用户在纸上「预演」了九世善珠的珠串九个月。珠宝的种草不靠广告位，靠这一页的每一次落印。

**④ 珠中有本**
珠宝端开一条**注珠**定制线：完成特定里程碑的人，可在珠内侧刻上专属印记——
- 走完九世的第九人：刻「本子编号 + 归藏」；
- 任何一世的注释者：刻「本子编号 + 第 N 世」；
- 写满 32 问的人：刻「三十二问 · 全注」；
- 年度传灯者（九灯全亮）：获得「传灯者珠」定制资格。
每颗注珠对应一本真实流转过的本子、一段九个人的故事。**珠宝的溢价不在克重，在故事的唯一性——这是任何珠宝同行都抄不走的产品。**

### 3.4 已有资产的改造清单（拿来就能排期的部分）

| 已有资产 | 改造动作 | 产出 |
| --- | --- | --- |
| 译本（已完成） | 按三十二分拆条；每分提炼「三行白话」进本子左页；全文放扫码页 | 32 个扫码落地页 + 32 段「三行白话」 |
| 视频课程（已有） | 按 32 问重新切片，每条 3–5 分钟；另加 1 条十分钟总纲（「为什么是 32 个问题」） | 33 条短课，挂扫码页 |
| 珠宝产品线 | 新增「注珠」定制服务（刻编号）与「传灯者珠」资格款；主产品线不动 | 一条定制线、一个资格款 |
| 100 场公益 | 升级为「原点本」首发网络：每场活动发出一批编号本 | 首发渠道 + 每场活动的新叙事 |
| 金刚兄弟社群 | 承接「接本池」（想接本的人排队匹配）与断点复活的人工兜底 | 流转保障 + 社群新任务 |
| 九灯印小程序（2026 案） | 扩展「本子档案」：编号、九世注解、流转地图 | 数字孪生 + 数据资产 |

## 第四部分 · 商业模式与三条不可越的线

### 4.1 钱从哪里来，到哪里去（一句话版本）

> **免费的本子创造付费的意义：本子花的钱，是珠宝挣回来的；珠宝好卖，是因为本子给了它别处买不到的意义。**

- 成本端：本子印制 + 首发物流 + 断点补寄 + 小程序扩展（一次性）；
- 收入端：注珠定制与常规珠宝的自然转化、课程轻付费（随喜或会员，定位为覆盖制作成本，不做利润主力）；
- 健康度指标：**一本本子在九世旅程中带来的珠宝自然转化**（预期不需要很高——一本触达九人，只要极小比例在终点选择纪念，模型即成立）。

### 4.2 三条不可越的线（融合的安全边界）

1. **购买不加速任何进度。** 买珠宝不能多点珠印、不能插队接本、不能加速九灯——善事系统与消费系统**单向连通**：善行可以解锁购买资格，购买永远不能解锁善行进度。
2. **本子链路里零推销。** 本子、扫码页、视频课全程无购买入口；注珠资格只在用户完成里程碑时**被告知**，入口藏在「我的档案」里，愿者自取。
3. **口径红线延续。** 全链路只讲文化、家风、陪伴、纪念；不讲功效、不讲开光、不讲转运；课程定位为文化讲读。

> 这三条线不是自缚手脚——它们正是「注珠为什么值钱」的原因：**因为资格不能买，所以资格才值得纪念。**
