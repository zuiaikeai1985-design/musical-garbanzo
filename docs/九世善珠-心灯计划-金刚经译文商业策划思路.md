# 《心灯计划》——金刚经译文双轮商业策划思路稿

**案名：** 心灯计划（左手善念，右手传灯）
**本稿性质：** 商业策划思路稿——以叶茂中「冲突营销」与华与华「超级符号」双方法论推演，落到可执行路径
**资产底盘：** 《人间注》创意（半本书 · 九人一本）｜ 闻思修架构 ｜ 2026 传灯 · 九灯计划 ｜ 100 场公益 ｜ 金刚兄弟社群
**你的两只手：** 右手——译文笔记本、解读视频课（小鹅通）、368 定制挂坠；左手——捐赠阶梯与寺庙融合

## 第一章 · 先把事情想清楚：这门生意的本质三问

任何大师接案子，第一件事不是想创意，是想清楚三个问题：

**问一：我们到底在卖什么？**
不是卖书，不是卖课，不是卖挂坠。**我们卖的是「安心」**——书是安心的入口，课是安心的路径，挂坠是安心的随身凭证。三样货，一个购买理由。

**问二：凭什么是我们？**
一百场公益攒下的信任 + 九世善珠的品牌母题（九、珠、灯、传）+ 已经做好的译本和课程。**别人有货没故事，我们有货、有故事、还有一群已经相信故事的人（粉丝群体）。**

**问三：这门生意最怕什么？**
最怕「以公益之名行卖货之实」被识破——所以本案的铁律是：**善念链路与生意链路分开走账、分开说话，让捐的人体面，让买的人值得。**（详见第八章红线）

## 第二章 · 叶茂中之眼：找到那个尖锐的冲突

### 2.1 冲突洞察

叶茂中说：营销的本质是洞察需求，需求藏在冲突里。

当代人最大的冲突是什么？

> **日子越过越忙，心越来越慌；手机里什么都有，就是没有安心。**

想安心的人去哪了？心理咨询太贵还有病耻感；鸡汤不解渴；寺庙旅游拍张照，回来该慌还是慌。——**「安心」是全中国最大的未被满足的需求。**

### 2.2 天赐的产品匹配

《金刚经》整部经的缘起，就是须菩提替所有人问了一句：

> 「应云何住？云何降伏其心？」——**心该放在哪？心慌了怎么办？**

**这部千年经典的第一问，就是当代人的第一冲突。** 我们不需要制造需求，只需要把这个千年之问翻译成今天的话：

> **「心慌的时候，把心放在哪？」**

这就是全案的引爆点：一个问题，而不是一个卖点。产品（金刚经译文）与冲突（心慌）同源同根——这种匹配度，是策划人一辈子难遇几次的。

### 2.3 冲突的三级放大（传播弹药）

- 对年轻人：「躺也躺不平，卷也卷不动——心慌的时候，把心放在哪？」
- 对中年人：「上有老下有小，谁问过你心里慌不慌？」
- 对老年人：「儿女都好，就是夜里睡不踏实。」

同一个冲突，三代人三种慌。**一问通吃全人群，这就是话题引爆的底气。**

## 第三章 · 华与华之手：超级符号与播传句

### 3.1 文化母体（不发明，只嫁接）

华与华说：超级符号就是把品牌嫁接到人人熟知的文化母体上。本案嫁接四个母体，全部零教育成本：

| 文化母体 | 嫁接到 | 人人皆知的原型 |
| --- | --- | --- |
| 灯（长明灯、心灯、传灯） | 全案总符号 | 「点灯」= 祈愿 + 希望 |
| 功德 | 捐赠体系 | 功德簿、行善积德 |
| 平安符 / 随身信物 | 368 挂坠 | 中国人最大的随身信仰刚需 |
| 蚂蚁森林式「种树」 | 心灯地图 | 国民级公益游戏化心智 |

### 3.2 视觉锤与语言钉

- **视觉锤：** 暗夜里的一盏暖金灯（延续品牌黑金体系，所有物料只此一个画面母题）。
- **语言钉（播传句）：** 主句就是那一问——**「心慌的时候，把心放在哪？」**
  配套的回答句，按场景分工：
  - 卖书答：「先写你的日子。」（人间注）
  - 捐书答：「捐一本书，点一盏灯。」
  - 请坠答：「请一盏随身的灯。」
- 播传的检验标准：用户会不会**原话转述**。「捐一本书，点一盏灯」七个字，发朋友圈不用改一个字。

### 3.3 数字符号化：368 不是价格，是编码

368 元的挂坠，把定价变成文化资产：

> **3 = 三世（过去 · 现在 · 未来）｜ 6 = 六度（布施 · 持戒 · 忍辱 · 精进 · 禅定 · 般若）｜ 8 = 八正道**

「三六八，请一盏心灯」——价格自己会说话，导购不用背话术。

## 第五章 · 病毒传播引擎五件套（在粉丝群体中快速引爆）

### 引擎一：一问挑战——#心慌的时候把心放在哪#

- 抖音 / 视频号 / 小红书发起话题挑战：素人对镜头回答这一问，答案即内容（回答门槛为零，情绪浓度极高）。
- 启动方式：先从九世善珠自有粉丝群与金刚兄弟社群发起「百人答」——一百个真实粉丝的回答剪成系列短片（每条 15 秒，黑底金字），话题下挂载小鹅通课程与购书链接。
- 为什么会火：**问题比答案更传播。** 每个人都被这一问击中过，评论区自动变成故事池。

### 引擎二：注卡——人人可晒的社交货币

- 买书人写下第一句注解后，扫码生成专属「注卡」：黑金卡面 + 你的一句话 + 对应经文一句 + 你的灯编号。
- 晒卡即传播，卡上的码直达购书 / 捐书页。**UGC 就是广告，用户就是媒介。**

### 引擎三：心灯地图——蚂蚁森林母体的公益游戏化

- 每卖一本、每捐一本，全国地图实时点亮一盏灯；个人主页显示「我点亮的灯」。
- 年度目标叙事：**「一起点亮一百万盏灯。」** 数字每天在涨，传播每天有素材。
- 蚂蚁森林证明过：中国人愿意为「可视化的善意累积」持续行动并主动炫耀。

### 引擎四：买一捐一——购买行为自带善行叙事

- 第一轮发售即承诺：**你买一本，品牌以你的名义捐一本进「迷茫者书库」。**
- 买书人同时获得：自己的书 + 一张「代捐点灯证」（写着受赠方向）。
- 晒单理由天然成立：「我买了本书，顺便点了一盏灯。」

### 引擎五：九世漂流反馈——让捐赠「活着」

- 捐出的书按《人间注》九人一本机制流转，捐赠人随时可见：我捐的书走到第几世、被写下了什么注解。
- **大多数公益捐完即失联，我们的捐赠会回信。** 这是复捐率与二次传播的核心引擎——收到第一条「你的书被写下了新注解」推送的人，没有不截图发圈的。

## 第六章 · 两轮发售节奏（右手的打法）

### 6.1 为什么必须分两轮

> **第一轮用内容养信任，第二轮用信物收利润。**

- 第一轮（书 + 课）亲民定价走量：筛出「真的读进去的人」，蓄起心灯地图与注卡声量；
- 第二轮（368 挂坠）只向第一轮用户开放优先资格：**被内容打动过的人，转化率与客单接受度完全不同**；且「凭资格请」本身制造稀缺与荣誉。

### 6.2 第一轮：闻思产品包（译文笔记本 + 视频课）

| 项 | 设计 |
| --- | --- |
| 产品 | 《人间注》译文笔记本（32 问 + 三行白话 + 留白作注）；解读视频课上架小鹅通（按 32 问切片 + 1 条总纲），抖音挂载 + 线下扫码 + 社群内播 |
| 定价原则 | 书低于百元（结缘感），书课包轻溢价；**捐赠通道按印制成本价另计（如每本 25 元级），与零售价严格分开、成本公示** |
| 首发 | 粉丝内测（编号本 + 老粉优先）→ 公开发售（买一捐一）→ 话题挑战同步引爆 |
| 关键动作 | 每本书页角扫码进课程（本中有课）；每条课尾一句「写在你的本子上」（课中有本） |

### 6.3 第二轮：368 传灯坠（修的信物，利润品）

| 项 | 设计 |
| --- | --- |
| 命名 | **传灯坠**——把 2026 年度主题戴在身上 |
| 造型建议 | 灯焰 + 珠的合体（焰中有珠 / 珠上有焰），黑金材质语言与品牌同源；内刻「应无所住」四字 |
| 数字编码 | 368 = 三世 · 六度 · 八正道（导购一句话讲完） |
| 发售资格 | 第一轮购书 / 听课 / 捐书用户优先请购；附「点灯证书」，绑定你的灯编号——**每一枚坠子对应地图上一盏真实的灯** |
| 场景主打 | 重阳节点主推「给爸妈请一盏随身的灯」（孝心场景，368 客单顺理成章）；亦适配「给迷茫的朋友」赠礼场景 |
| 口径红线 | 只讲「陪伴 · 提醒 · 纪念」，不讲护身功效、不讲开光加持（文化寓意表达） |
| 利润承诺 | 公开承诺每枚坠子提取固定金额（如 36.8 元）注入书库印制基金——**利润的一部分变成下一批灯** |

## 第七章 · 左手：捐赠阶梯设计（合规修订版）

### 7.1 阶梯与权益（保留你的刻度，权益重新编排）

| 捐赠量 | 权益 | 设计逻辑 |
| --- | --- | --- |

| 1000 本 | 该批次笔记本扉页印名：「此批心灯由 ××× 与九世善珠共同点亮」 | 名字随书流转九世，是最贵的留名 |
| 5000 本 | 年度「联合发起人」：寺庙公益项目发起人名录留名 + 冬至归一夜联合点灯人 + 年度纪录片鸣谢 | 见 7.2 重要修订 |

### 7.2 一处必须的修订（专业提醒）

你原设想的「5000 本可参与九世善珠与寺庙合作中的份额」——**「份额」二字碰不得**：宗教场所严禁投资承包与商业分成，涉「份额回报」还可能触及非法集资。
修订方案：把「利益份额」换成**「发起人荣誉」**——名录刻名、联合点灯、纪录片鸣谢、优先共建权（下一座寺庙合作项目的优先冠名捐赠资格）。**名与誉给足，利一分不碰**——这不仅是合规，更是让大额捐赠人体面：他买的本来就不是回报，是身后名。

### 7.3 资金口径（左手的生命线）

- 捐赠资金**只对应书的印制与送达成本**（每本成本构成公开：纸张 / 印装 / 物流），经具备公开募捐资格的慈善组织专项管理、定期公示；
- 品牌营销、课程制作、挂坠生产费用**一律不从捐款出**——「所有捐款用于译文发布全过程」这句口径要收窄为「**所有捐款用于书的印制与送达，全程公示**」，否则将来解释不清；
- 买一捐一中「捐」的成本由品牌销售利润承担，属品牌自有公益支出，与公众捐款分账。

## 第八章 · 寺庙深度融合（江门观音寺 / 东华禅寺）

### 8.1 角色定位

寺庙是**传灯道场**（文化与公益场域），不是销售渠道。四个共建，全部落在文化 + 公益：

1. **结缘书架**：寺内设《人间注》结缘点——受捐书库的流向之一，香客扫码登记即可请书（免费结缘，线上完成登记，现场无交易）；
2. **福报分享会**：季度一场，500 本档捐赠人受邀现场分享（定位文化分享会，非法会）；
3. **节点共办**：咬合九灯计划——腊八施粥赠书、浴佛节点灯、冬至归一夜；
4. **归一夜主场**：每年冬至，年度功德簿揭幕 + 传灯人齐聚 + 走完九世的本子归档仪式。

### 8.2 两寺怎么选（建议，需实地对接后定）

| | 东华禅寺（韶关） | 江门观音寺 |
| --- | --- | --- |
| 人群契合 | 禅修营体系成熟，年轻访客比例高，与「迷茫青年」目标人群重合度高 | 地处著名侨乡，利于海外华人捐赠与「侨批家书」式情感叙事 |
| 建议角色 | **主道场**：结缘书架 + 福报分享会 + 归一夜 | **节点道场**：面向侨胞的「越洋点灯」专场（海外游子为家乡父母捐书点灯） |

> 「越洋点灯」是江门侨乡独有的富矿：游子在海外扫码捐书，灯点在家乡地图上，书进侨乡中学——这条线做好了，自己会上新闻。

### 8.3 合规框架（三条铁律）

1. 与寺庙之间**只有公益共建协议，没有商业分成**；
2. 寺庙场域内**无任何销售行为**（请书是登记结缘，请坠回线上完成）；
3. 一切善款走正规慈善组织专项通道，寺庙与品牌互不经手对方资金。

## 第十章 · 算账逻辑（定价与资金流三分法）

```
资金流一 · 零售（书 + 课）     → 覆盖内容与运营成本 + 承担「买一捐一」的捐赠成本
资金流二 · 挂坠（368）        → 利润主力；每枚固定提取 36.8 元注入书库印制基金（公示）
资金流三 · 公众捐赠           → 只进慈善组织专项账户，只用于书的印制与送达，全程公示
```

三条资金流**各走各账、各说各话**：买的人知道钱买了什么，捐的人知道钱去了哪，请坠的人知道利润里有一部分变成了灯。**账目透明本身，就是本案最大的品牌广告。**

## 第十一章 · 红线清单（做之前必须钉死的五颗钉子）

1. **「份额」改「荣誉」**（见 7.2）——大额捐赠权益全部荣誉化，不碰利益分配；
2. **捐款用途口径收窄**——「用于书的印制与送达」，不含营销与商品成本；
3. **挂坠不讲功效**——护身、辟邪、开光、转运四词全链路禁用，只讲陪伴与纪念；
4. **寺庙场域零交易**——结缘登记与销售严格分离；
5. **课程定位文化讲读**——不以品牌名义讲经说法，符合互联网宗教信息服务管理要求。

**这五颗钉子不是束缚——它们是这门生意能做十年的地基。**
