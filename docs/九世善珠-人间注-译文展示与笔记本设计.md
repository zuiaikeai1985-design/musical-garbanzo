# 《人间注》译文展示与笔记本设计

**本稿性质：** 产品形态与物设计方案——回答两件事：金刚经译文还能以什么形式被看见；若做笔记本，具体怎么设计。
**设计原则：** 译文不是被「印」在纸上给人读完的，是被「藏」在纸里给人揭开、写下、寄出的。
**与前稿关系：** 32 问、一书两版、指名答问帖，全部落到一本可摸到的东西上。

---

## 0. 先换一个问题

普通做法：精装书，左原文右白话，读完即结束。
问题不在印得好不好，而在**形态默认了「读」**——读不懂的人，翻两页就放下。

换一个问题：

> **这本东西打开的时候，人的第一动作应该是什么？**
> 不是读，是**揭、写、撕、寄**。

译文的展示，要从「出版物」改成「可被使用的器物」。下面五个形态，都按这个标准来想。

---

## 1. 五种展示形态（从轻到重）

### 形态 A · 日课签筒（最轻，随手抽）

- **是什么：** 一只黑金小筒，内装 32 张问签。每天抽一张：正面一问，背面三行白话 + 原文一句。
- **译文怎么展示：** 一天只给一分，不整本压人。抽到哪分，就只读哪分。
- **适合：** 入门礼、门店陈列、寺庙结缘架、买一捐一的「迷茫者书库」轻量版。
- **缺点：** 写不下长注，不能漂流。

### 形态 B · 经折注本（最像经，最好看）

- **是什么：** 传统经折装（左右拉开如屏风），一共 32 折。
- **译文怎么展示：** 每一折是一块「屏」——上沿极细原文，中部烫金一问，下半整块留白。拉开时 32 问连成一条人生长卷。
- **适合：** 礼赠、寺庙展示、冬至归一夜的「打开仪式」（当众拉开长卷）。
- **缺点：** 不好随身写，批量印刷成本高于普通锁线。

### 形态 C · 信封本（最新，最贴指名答）★ 推荐主形态

- **是什么：** 32 个信封订成一本。每一个信封 = 《金刚经》一分。
- **译文怎么展示：**
  - 信封封面：只印人生之问（烫金一行）；
  - 拉开信封口：内侧左翼是原文小段，右翼是三行白话；
  - 信封里：一张空白信笺，给你写；
  - 信笺可抽出来，装回或寄给一个人——**实物版指名答**。
- **适合：** 自留本零售、漂流本、指名答的线下闭环。
- **为什么成立：** 「打开信封」本身就是仪式；译文被藏在信封内侧，必须伸手才看见——**先有动作，才有阅读**。看不懂的人，至少完成了「拆开」和「写下」。

### 形态 D · 双层揭页本（最有层次）

- **是什么：** 普通锁线本，但每一分是三层纸叠在一起。
- **译文怎么展示：**
  - 第一层半透明宣纸：印原文（字淡、可透）；
  - 揭开宣纸：第二层是白话三行 + 人生之问；
  - 翻到背面：整页留白作注。
- **阅读顺序被物规定了：** 先看见看不懂的原文 → 揭开才看见白话 → 再翻页写自己的日子。这个顺序就是「闻 → 思 → 修」的纸上版本。
- **适合：** 中高端自留本、收藏款。
- **缺点：** 工艺复杂，不适合十万级捐赠印量。

### 形态 E · 边注经卷（最观念，最贵）

- **是什么：** 一张可展开的长卷，或精装对页。版心（中间最大块）是空白；左右窄栏才是原文和白话。
- **观念：** 经文成为你日子的边框，主角是你写的字，不是佛说的字。
- **适合：** 限量收藏、寺庙供奉展示，不做走量。

**落地建议：**
- **走量主货：形态 C 信封本**（自留本 + 漂流本共用模具，封面区分）；
- **节点礼赠 / 归一夜道具：形态 B 经折注本**（小量精做）；
- **最低成本结缘：形态 A 日课签筒**（书库、寺内结缘架）；
- 形态 D、E 做年度限量，不进主货盘。

## 2. 主货设计：信封本《人间注》怎么做

下面全部按形态 C 写死，可直接给设计和印刷厂。

### 2.1 开本与手感

| 项 | 规格 | 理由 |
| --- | --- | --- |
| 开本 | 148 × 210 mm（A5 竖） | 单手可持，放进中号信封能邮寄；不像大书那样「我在读经」 |
| 厚度 | 约 18–22 mm（32 封 + 前后环衬） | 有器物感，不笨重 |
| 封面 | 黑色特种纸 + 暗金烫一问或一只灯印，**无佛像、无经题大字** | 社交安全：放在咖啡馆桌上，看不出是宗教书 |
| 封面字 | 自留本烫「我注」；漂流本烫「人间注」+ 流转编号 | 一书两版一眼可辨 |
| 函套（可选） | 硬纸灯匣，匣脊印九灯日期 | 礼盒款；平装零售可去掉以控成本 |
| 内纸 | 信封用 120g 米色；信笺用 90g 微黄书写纸（钢笔不洇） | 拆得开、写得住 |
| 装订 | 上边或左侧穿孔，棉线锁成册；信封口朝外或朝上 | 抽出信笺不影响成册 |
| 附件 | 一枝软炭铅笔或一支暗金中性笔；九张灯签（漂流本另加九枚珠印贴纸） | 打开就能写，不另找笔 |

封面测试题（沿用燎原军规）：**把这本东西放在星巴克桌上，邻座看一眼，不该立刻联想到寺庙。**

### 2.2 一个「分」的结构（翻开后的四层）

以第十分为例，说明使用者的手怎么动、眼看见什么。

**① 信封封面（未拆）**
- 只有一行字：「什么事，让你到现在还放不下？」
- 右下极小：第十 · 庄严净土分
- 不出现「金刚经」三个大字（降低社交风险；拆开后才现身）

**② 拉开封口 · 左翼（原文）**
- 鸠摩罗什本该分节选 4–6 行，字号小、字色暗金、行距疏；
- 不做标点讲解，不做注释堆叠；
- 作用：让人感觉「底下有经」，而不是逼人读完。

**③ 拉开封口 · 右翼（白话 + 三行）**
- 第一行：人生之问（与封面同一句，字稍大）；
- 下三行白话（从已有译本压缩，口语，不超过 60 字）；
- 最底一行小字：「这一问，你的日子怎么答。」
- 内侧右下角：一枚 8mm 珠印码（扫开即 H5：完整译文 → 3 分钟课 → 别人的答案 → 写下）。

**④ 抽出信笺（作注页）**
- 几乎全白，天头一行淡灰小字：「第十问 · 写给自己，或寄给一个人。」
- 地脚：自留本印「我注 · 第十分」；漂流本印「第 □ 世 · 笔名 ______」+ 珠位小圈。
- 信笺背面：空白收件栏 + 「寄出前请先自己写一句」（对接指名答双盲：寄之前必须自己落笔）。
- **可抽出、可装回、可单独装进配套小信封寄出。**

手的顺序被设计成：看见问题 → 好奇拆开 → 瞥见原文 → 读三行白话 → 抽出纸来写。**译文出现在第三步，不是第一步。**

### 2.3 全书骨架（除了 32 封还要什么）

| 页序 | 内容 |
| --- | --- |
| 环衬 | 纯黑，中央一粒暗金点（灯） |
| 扉页 | 「人间注」三字 + 一句：「半本书，另一半是你。」 |
| 用法页（1 页） | 四行说明：拆开读三行 → 写下 → 可寄出 → 扫码可听。不写教义。 |
| 目录 | 四辑：安 / 放 / 舍 / 观，每辑下列八问（只列问，不列经名） |
| 信封 01–08 | 第一辑 · 安 |
| 辑隔页 | 一张深色卡纸，只印一个字「放」——进入第二辑 |
| 信封 09–16 | 第二辑 · 放 |
| 辑隔页 | 「舍」 |
| 信封 17–24 | 第三辑 · 舍 |
| 辑隔页 | 「观」 |
| 信封 25–32 | 第四辑 · 观 |
| 九世页（仅漂流本） | 九个珠位，盖满即归档；扫码看本册流转地图 |
| 末页 | 标版：九世善珠 / guard the love / 为爱付出，护佑一生；不印价格、不印店名 |

自留本无九世页，末页改为：「写满之后，可扫码将此本『转世』为一本漂流本。」

### 2.4 自留本 vs 漂流本（同一模具，三处不同）

| | 自留本 · 我注 | 漂流本 · 人间注 |
| --- | --- | --- |
| 封面烫印 | 「我注」 | 「人间注」+ 编号 |
| 信封口 | 可反复开合（子母扣或细绳） | 同上，另加「第 N 世」贴纸位 |
| 信笺地脚 | 「写给自己」 | 「第 □ 世 · 笔名」+ 珠圈 |
| 九世页 | 无 | 有 |
| 附件 | 笔 + 九张灯签 | 笔 + 灯签 + 九枚珠印贴 + 一张传灯帖（转交给下一人时夹在书里） |
| 定价逻辑 | 零售（第一轮） | 只捐不卖 |

印刷上共用信封刀模和内文文件，变的是封面烫印、地脚文字、是否加九世页——**一套文件出两个 SKU，控成本。**

### 2.5 排版与字体（译文怎么「长」在纸上）

- **人生之问：** 封面与右翼主标题，用毛笔感或宋切大字，一行排完；字要少、要烫金或厚墨。
- **原文：** 细宋 / 楷，字号 8–9 pt，暗金或深灰，绝不粗黑——原文是「远景」，不是正文。
- **三行白话：** 书宋或细黑体 11–12 pt，墨色为正，行长不超过 16 字，方便一口气读完。
- **作注提示：** 细线、淡灰，像信纸上的信头，不是标题。
- **全本无拼音、无注释编号、无「注 1 注 2」**——那是教科书，会把人推开。
- **经名「金刚经」只在用法页与末页各出现一次**，中间 32 封只见问、不见经名。

### 2.6 扫码在本子上的位置（本中有课）

- 每封内侧右下，一枚 8mm 暗金珠形码，不像普通二维码那么「电商」；
- 扫开四屏（沿用落地执行案）：完整译文 → 3 分钟课 → 别人的答案 → 你来写（可同步到数字档案，纸上那张信笺仍是主件）；
- 封面内侧印一枚总码：进入「我的 32 问进度」。

## 3. 三种人，三种打开方式（设计要服务动作）

| 人 | 他会怎么用 | 本子要成全他 |
| --- | --- | --- |
| 只想被安慰的人 | 抽一封，读三行，写一句，合上 | 信封可单拆，不必按序；目录按「问」检索 |
| 想搞懂经的人 | 拆开读原文 + 扫码听课 + 对照译本全文 | 左翼有原文，码后有全文，课按分切片 |
| 想把问寄出去的人 | 自己先写背面，信笺抽出，寄给一个人 | 信笺独立、有收件栏、有双盲提示 |

一本书同时服务这三种人，靠的不是加页，是**每一封都完整包含：问、原文、白话、空白、码、可寄。**

---

## 4. 和指名答、捐赠、368 坠怎么咬合

- **指名答的实物版：** 抽出信笺 = 发出一封问帖。数字问帖是线上；信封本是手上。同一套话术（四类关系附言印在传灯帖背面，寄出时可选抄一句）。
- **买一捐一：** 顾客手上是自留本（信封可反复开合，信笺装回）；书库里是漂流本（九世页 + 传灯帖）。
- **日课签筒：** 32 问与信封本同一套文案，签筒是「预告片」，信封本是「正片」。
- **368 传灯坠：** 不进本子内页。写满 32 封或走完九世的人，在数字档案里出现「请坠」入口——物与物分开，资格在旅程终点。
- **灯签：** 夹在函套或环衬袋里，九张，可贴、可拍、可晒，不占用 32 封的结构。

## 5. 打样与成本的执行顺序（给生产和设计）

| 次序 | 做什么 | 验收 |
| --- | --- | --- |
| 1 | 出第十分的「一封完整样品」（封面问 + 两翼 + 信笺 + 珠码） | 手感、拆开顺序、字号、社交安全感（桌上测） |
| 2 | 出四辑隔页 + 扉页 + 用法页 | 四字「安放舍观」是否立得住 |
| 3 | 自留 / 漂流封面烫印对比 | 三米外能分清两个 SKU |
| 4 | 小批量 50 本（25+25）给金刚兄弟试用两周 | 问：拆不拆得开、写不写得下、寄不寄得出、会不会羞于外带 |
| 5 | 改刀模与纸张后，定第一轮大货（中秋首发） | 锁文件、锁纸厂 |

**不要一上来印 32 封全本。** 先把「一封」做到让人想拆开第二封，再开全本。

## 6. 一封的文案示意（第十分，供设计直接排）

**封面**
什么事，让你到现在还放不下？
第十

**左翼原文（节选示意，以译本作者核定为准）**
庄严佛土者，即非庄严，是名庄严。
是故须菩提，诸菩萨摩诃萨应如是生清净心，
不应住色生心，不应住声香味触法生心，
应无所住，而生其心。

**右翼白话（三行，示意）**
心可以路过一切，别在任何地方过夜。
你抓住的东西，往往是抓住你的东西。
先放下手里的，心才有地方可去。

**信笺天头**
第十问 · 写给自己，或寄给一个人。

## 收束

> 普通译文本问的是：字印得清不清。
> 《人间注》问的是：**手下一步要做什么。**
>
> 拆开信封，才看见译文；
> 抽出信笺，才轮到自己；
> 寄出去，这一问才变成两个人的事。
>
> 笔记本不是容器，是一套动作的说明书——
> **揭、写、寄，译文只是夹在动作中间的那一层纸。**
