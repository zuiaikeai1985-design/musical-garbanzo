# 《人间注》创意思路稿

**项目缘起：** 百场公益之后，把《金刚经》译文做成笔记本，邮寄／传递给大家
**本稿性质：** 创意思路稿（供立案讨论），**不是完整策划案**
**一句话思路：** 别送一本「译好的书」，送一本**只写了一半的书**——另一半，由收到的人用自己的日子写完，写完，传给下一个人。

---

## 1. 先诊断：直接邮寄译文本，会损失什么

原始想法（印译文 → 邮寄 → 送达即结束）是一件扎实的善事，但有三个天然损耗点：

1. **译文解决不了「看不懂」。** 看不懂《金刚经》的人，拿到译文多半还是看不懂——因为难的不是字面，是「这跟我的生活有什么关系」。**理解的钥匙不是更好的翻译，是参与。**
2. **邮寄即终点。** 单向赠送没有回流：本子寄出去，故事就断了。一百场公益攒下的势能，变成一次性的物流成本。
3. **纯经文出版物有合规敏感。** 商业主体大规模传播宗教经典译文，容易被归入宗教宣传品范畴；这件善事需要一个**落在文化与生活方式上的产品定位**来做安全垫。

> 结论：笔记本这个载体选得很对（笔记本天然是「写」的，不是「读」的），但要把它从「赠品」变成「行为」。

---

## 2. 核心创意：三个反转

### 反转一（产品）：从「译好的书」到「半本书」

《金刚经》三十二分，本来就是一场问答——须菩提问，佛陀答。我们把它还原成问答体，重构为 **32 个人生之问**：

- 「应云何住？」→ **心慌的时候，把心放在哪？**
- 「凡所有相，皆是虚妄」→ **你有没有被一个「人设」困住过？**
- 「应无所住，而生其心」→ **有没有一次付出，你没想过回报？**

笔记本每一分只占一个对页：
**左页极简**——问题一行、原文一小段、白话三行，到此为止；
**右页全白**——只印一行小字：「这一问，你的日子怎么答。」

看不懂经文没关系。**先写你的日子，日子会替你翻译。**
使用者不是读者，是**注释者**——这是「我注六经，六经注我」的老典故，也是这本笔记本的全部产品哲学：

> **书名即思路：《人间注》——金刚经的白话，由人间的日子来作注。**

### 反转二（流转）：从「品牌邮寄」到「九人一本」

本子不邮寄到人，本子**在人和人之间走**：

- 每本《人间注》有独立编号，内页九个珠位（呼应九世善珠的九颗珠）。
- 每位使用者持有期间，至少写下**一句注解**（一句就够，写满全本也随喜），在珠位盖一枚珠印，然后**亲手交给或寄给下一个人**——家人、朋友、同事，或社群里报名接本的陌生人。
- 一本本子流转九人，谓之**「一本九世」**。第九位使用者获得永久收藏权——「传到我为止」是仪式，也是稀缺。
- **传本即传灯。** 这就是 2026「传灯」年度主题在实物上的落点：灯是抽象的，本子是具体的；每一次转交，都是品牌叙事被普通人亲手复演一次。

物流反转的现实收益：品牌只负担首发批次与断点补寄，**人传人替代全量邮寄**——成本变成了连接。

### 反转三（沉淀）：从「送出去」到「收回来」

- 本内印码，扫码即登记流转（可直接扩展九灯印小程序）：每一本的「前几世注解」线上可见——你翻开本子之前，先看见前面几个陌生人如何用日子回答同一问。
- 走完九世的本子，内容脱敏后扫描入**「人间注疏」数字长卷**——千万个普通人给《金刚经》作的注，逐年累积。这是品牌能攒下的最硬的内容资产：**不是我们解释了金刚经，是人间解释了金刚经。**
- 每年冬至「归一夜」（九灯计划第九灯），揭幕当年注疏长卷、为走完九世的本子举行「归档」仪式——与年度策划的收官闭环严丝合缝。

## 3. 这个思路为什么成立

| 维度 | 依据 |
| --- | --- |
| 解决真痛点 | 「写」是最低门槛的「懂」：一天一问、一句注解，参与即理解，不逼人啃全文 |
| 品牌同构 | 九人一本 = 九世一珠；传本 = 传灯；珠印 = 九灯印——「九、珠、灯、传」四个品牌母题全部复用，无需新概念教育 |
| 文化有根 | 问答体是《金刚经》原生结构；「我注六经，六经注我」是现成的文化母题，讲得出、站得住 |
| 传播自带故事 | 每本本子是一条九人接力的故事线（可追踪、可回看、可报道）；「第九人收藏权」制造传播记忆点 |
| 合规安全垫 | 定位「生活注释笔记本 / 文化项目」：白话意译 + 大比例留白 + 无宗教符号封面（延续黑金极简）；只结缘不售卖；首发走线下公益场景 |
| 成本可控 | 首发一批 + 断点补寄，其余流转由用户完成；一本服务九个人，单人触达成本约为直邮的九分之一 |

## 4. 机制骨架（一页速览）

```
100 场公益现场（原点）
   │  首批「原点本」编号发出——从善行里长出来的书
   ▼
第 1 世使用者：翻到戳中自己的那一问 → 写下一句注解 → 盖珠印
   │  亲手转交 / 寄给下一人（扫码登记，线上可见前世注解）
   ▼
…… 第 2 世 → 第 9 世（一本九世，珠位盖满）
   │
   ├─ 第九人：获得收藏权，本子留在他家
   ▼
「人间注疏」数字长卷（脱敏扫描，逐年累积）
   │
   ▼
每年冬至 · 归一夜：年度注疏揭幕（接入九灯计划第九灯）
```

配套的三个小机制：

1. **接本池：** 线上报名「我想接一本」，为传不下去的本子匹配下一世（防断流）。
2. **断点复活：** 本子丢失／滞留超 60 天，持有者扫码申请「续世」，品牌补寄新本、继承编号与已有注解（线上打印成扉页）。
3. **防截流：** 只有「传出去且下一世登记」才点亮你的珠印——收藏欲被引导到「第九世」这个正当出口。

## 5. 留给策划案阶段的问题清单

思路若被采纳，全案需要回答这九个问题（按优先级）：

1. **32 问文案**：三十二分各自对应哪个人生之问——这是全项目的内容心脏，值得最重的打磨投入。
2. **底本与译文**：以哪个公版译本为底（建议鸠摩罗什本），白话意译自撰还是外请；译文口径需过合规审。
3. **出版路径**：结缘赠阅印刷品的合规形态（内部资料性出版物 vs 正式书号）。
4. **首批规模**：原点本印量、从哪几场公益活动／哪些城市发出、首批种子用户画像。
5. **登记系统**：九灯印小程序扩展的开发量与数据合规（注解内容的授权与脱敏规则）。
6. **断点率假设**：漂流类项目的自然断流率较高，需设定可接受断点率与补寄预算。
7. **节奏咬合**：首发放在 2026 九灯计划的哪一灯（建议腊八「起灯」首发，冬至「归一」收官）。
8. **仪式设计**：第九人收藏仪式、归档仪式的具体形态。
9. **风险预案**：注解内容审核（防不当内容随本流转）、宗教口径红线的执行细则。

---

## 6. 一句话收束

> 我们不再把《金刚经》的答案寄给别人——
> 我们把**问题**传下去，让每个人交出自己的答案，再亲手交给下一个人。
> 一本九世，传本如传灯：**人间注，注人间。**
