# 《人间注》信封本 · 生产细化案

**本稿性质：** 上一稿（形态选型）的下一层——**工厂能报价、设计师能开文件**的规格书
**适用形态：** 信封本（主货）｜ 自留本「我注」× 漂流本「人间注」共模双 SKU
**交付对象：** 平面设计、印厂工艺、包装采购、项目统筹
**未定项标注：** 文中标 ◆ 的数字为建议值，需以首次打样实测与厂方工艺能力校准

## 1. 结构总览：一本书由什么组成

| 部件 | 数量 | 说明 |
| --- | --- | --- |
| 封面（含封底、书脊） | 1 | 黑特种纸裱灰板（硬面）或单层厚纸（平装） |
| 前置页 | 4 面 | 环衬 / 扉页 / 用法页 / 目录 |
| 辑隔页 | 4 张 | 安 · 放 · 舍 · 观 |
| 信封页 | 32 张 | 每张 = 一分（核心部件） |
| 信笺 | 32 张 | 每封内一张，可抽出、可寄出 |
| 九世页 | 1 张 | **仅漂流本** |
| 末页标版 | 1 面 | 品牌锁定 |
| 附件 | — | 笔 ×1、灯签 ×9；漂流本另加珠印贴 ×9、传灯帖 ×1、寄送小信封 ×3 |

**成品尺寸：** 148 × 210 mm（A5 竖）｜ **书脊厚 ◆18–22 mm**（以 32 封实测为准）

## 2. 信封页刀模（核心工艺，先定这个）

### 2.1 展开尺寸

信封页采用「**主页 + 双翼内折 + 底袋**」一体成型，一张纸开一封，不另贴袋。

```
        ┌──────────── 展开长边 ────────────┐
        │  左翼   │    主页（封面）  │  右翼  │
        │ 66 mm   │     148 mm       │ 66 mm  │
        └─────────┴──────────────────┴────────┘
                 展开总宽 ◆280 mm × 高 210 mm
        底部另留 28 mm 上翻成袋（装信笺）
        展开总高 ◆238 mm
```

| 项 | 规格 | 说明 |
| --- | --- | --- |
| 展开尺寸 | ◆280 × 238 mm | 单张开一封；建议对开纸拼版 4 封/大版 |
| 成品折后 | 148 × 210 mm | 与全书同尺寸 |
| 左右翼宽 | 各 66 mm | 内折后中间留 ◆16 mm 开口缝，方便双手拉开 |
| 底袋高 | 28 mm | 上翻粘合，形成信笺袋 |
| 装订边 | 左侧 12 mm | 打孔锁线区，**不印任何内容** |
| 出血 | 3 mm | 四周 |
| 折线 | 压痕 3 道（左翼、右翼、底袋） | 压痕深度以不爆色为准 |
| 粘合 | 底袋两侧点胶，**中间不粘** | 信笺可整张抽出 |

### 2.2 开合方式（二选一，打样对比）

| 方案 | 做法 | 优点 | 风险 |
| --- | --- | --- | --- |
| **A · 子母扣**（推荐自留本） | 左右翼交叠处压一枚暗金子母扣 | 反复开合手感好，像信 | 增加工序与单价 |
| **B · 细绳绕扣** | 右翼延伸一条 3 mm 棉绳 + 圆纸扣 | 更朴素，成本低 | 绕绳略慢，绳易磨损 |
| **C · 无扣自然内折** | 仅靠折痕合拢 | 成本最低，走量首选 | 久用易翘边 |

**建议：** 自留本用 A 或 B（礼感），漂流本用 C（要经九人反复开合，越简单越耐用）。

## 3. 用纸与工艺

| 部件 | 用纸 | 克重 | 工艺 |
| --- | --- | --- | --- |
| 封面 | 黑色特种纸（触感 / 棉质类） | 250–300 g | 暗金烫印（哑金）+ 局部压凹（灯印）；**不覆亮膜**，可覆哑触感膜防指纹 |
| 灰板（精装款） | 灰纸板 | 2 mm | 平装款不用 |
| 环衬 | 纯黑特种纸 | 140 g | 中央 4 mm 暗金圆点，烫印 |
| 扉页 / 用法页 / 目录 | 米色book纸 | 100 g | 单黑 + 暗金专色 |
| 辑隔页 | 深色卡纸（较封面浅一度） | 200 g | 单字压凹，无烫 |
| **信封页** | 米色特种纸 | **120 g** | 双面印；压痕 3 道；底袋点胶 |
| **信笺** | 微黄书写纸 | **90 g** | 单面淡印，钢笔不洇（需测） |
| 九世页 | 与信封页同纸 | 120 g | 九个珠位烫印圆环 |
| 函套（礼盒款） | 灰板裱黑纸 | 2 mm | 匣脊烫九灯日期 |

**印色方案：** 全书 **单黑 + 1 个暗金专色（Pantone 871C 或同类金）**，不用四色——省成本，也保证黑金调统一。烫印仅用于封面、环衬圆点、九世页珠环。

**环保与合规：** 采用可回收纸张，油墨符合食品级安全标准（本子会被反复触摸、可能被孩子接触）；漂流本需注明「本册将由多人传阅」。

- 白话每行 **不超过 16 字**，三行合计 ≤ 60 字；

- 全书无拼音、无注释编号、无页码装饰；
- 页码只在辑隔页背面出现一次（极小，35% 黑）。

## 5. 32 封文案排版模板（内容组按此填空）

每封需交付 5 个字段，设计按模板套用：

```
【字段 1｜分序】      第 ×× 分 · ××××分（如：第十 · 庄严净土分）
【字段 2｜人生之问】  ≤ 15 字，一行排完
【字段 3｜原文节选】  4–6 行，鸠摩罗什本，需译本作者核定
【字段 4｜三行白话】  每行 ≤ 16 字，共 3 行
【字段 5｜信笺天头】  第 ×× 问 · 写给自己，或寄给一个人。
```

### 示例（第十分，已填）

- **分序：** 第十 · 庄严净土分
- **人生之问：** 什么事，让你到现在还放不下？
- **原文节选：**
  庄严佛土者，即非庄严，是名庄严。
  是故须菩提，诸菩萨摩诃萨应如是生清净心，
  不应住色生心，不应住声香味触法生心，
  应无所住，而生其心。
- **三行白话：**
  心可以路过一切，别在任何地方过夜。
  你抓住的东西，往往也在抓住你。
  先放下手里的，心才有地方可去。
- **信笺天头：** 第十问 · 写给自己，或寄给一个人。

**内容组交付节奏：** 每辑八封为一批，四批交齐；每批交付后由译本作者核定字段 3、由 45 岁以上非项目成员校验字段 2 与 4 的可懂度。

## 6. 双 SKU 差异表（共模，只改这几处）

| 项 | 自留本 · 我注 | 漂流本 · 人间注 |
| --- | --- | --- |
| 封面烫印 | 「我注」 | 「人间注」+ 编号（可变数据烫印或喷码） |
| 编号 | 无 | **6 位流水号**，同步印在末页与九世页 |
| 开合方式 | 子母扣 / 细绳 | 无扣内折（耐用） |
| 信笺地脚 | 「我注 · 第 ×× 分」 | 「第 □ 世 · 笔名 ______」+ 珠位小圈 |
| 九世页 | 无（末页改「转世」引导） | 有 |
| 附件 | 笔 + 灯签 ×9 | 笔 + 灯签 ×9 + 珠印贴 ×9 + 传灯帖 ×1 + 寄送小信封 ×3 |
| 函套 | 礼盒款有 | 无（降本，且便于流转） |

**可变数据处理：** 编号建议用**激光雕刻或喷码**而非烫印（烫印可变数据成本高）；喷码位置在封面右下角，暗金色，8 pt。

## 7. 成本结构（占比制，用于比价与控本）

| 项 | 占单本制造成本比例 | 控本要点 |
| --- | --- | --- |
| 信封页印刷 + 刀模压痕 | ◆35% | 拼大版（4 封/大版）；刀模一次开、两 SKU 共用 |
| 封面（特种纸 + 烫印） | ◆20% | 平装可省灰板；烫金面积控制在 ◆15 cm² 内 |
| 信笺 + 内页 | ◆12% | 普通书写纸即可，勿用高价特种纸 |
| 装订（打孔锁线） | ◆13% | 锁线比胶装贵但必须（信封页需可翻折） |
| 附件（笔、灯签、贴纸） | ◆12% | 笔可选配；捐赠版可去掉笔 |
| 包装物流 | ◆8% | 漂流本无函套，减重减体积 |

**降本三条路（按优先级）：**
1. 漂流本去掉函套、笔、子母扣 → 预计降 ◆20–25%；
2. 首批印量集中（自留本 + 漂流本合并起印）→ 摊薄刀模与开机费；
3. 烫金改「专色印金 + 局部 UV」→ 视觉接近，降 ◆8%（需打样对比，礼盒款不建议）。

**报价需向厂方索取的三档：** 3,000 本 / 10,000 本 / 50,000 本，含刀模费与开机费明细。

## 8. 打样清单（分三轮，每轮有明确否决项）

### 第一轮：单封白样（不印内容）

- 交付：空白信封页 ×5（三种开合方式各若干）+ 信笺 ×5
- **验收 7 项：**
  1. 单手能否顺畅拉开双翼
  2. 信笺能否整张抽出且不刮边
  3. 折痕处是否爆色 / 起毛
  4. 装订边 12 mm 是否够穿线
  5. 90 g 信笺钢笔书写是否洇透（正反面测）
  6. 反复开合 50 次后翼边是否翘曲
  7. 底袋点胶是否牢固
- **否决项：** 抽笺刮边、钢笔洇透——任一出现即换纸重打

### 第二轮：单封彩样（第十分，全内容）

- 交付：完整第十封 ×3（含烫印）+ 封面小样 ×3（我注 / 人间注 / 编号喷码）
- **验收 6 项：**
  1. 22 pt 烫金问句在 3 米外可读
  2. 9 pt 原文暗金在室内灯下不吃力
  3. 三行白话一口气读完（找 5 人实测）
  4. 珠形码扫码成功率（不同手机 ×10 次）
  5. **桌面社交安全测试**：放咖啡馆桌上，问 5 位陌生人「这像什么书」——不得有 3 人以上答「佛经 / 宗教」
  6. 三米外能分清两个 SKU
- **否决项：** 社交安全测试不过 → 封面重设计

### 第三轮：整本样书 50 册（自留 25 / 漂流 25）

- 用途：金刚兄弟试用两周
- **回收问卷 6 问：**
  1. 你拆开了几封？
  2. 写了几封？
  3. 有没有把信笺寄/给出去？给了谁？
  4. 会不会带出门？会不会羞于被人看见？
  5. 最想改的一处是什么？
  6. 愿意为它付多少钱？（自留本定价参考）
- **放行标准：** 人均拆封 ≥ 5、写注 ≥ 2、外带意愿 ≥ 70%

## 10. 质检抽验标准（大货到仓）

| 项 | 标准 | 抽验比例 |
| --- | --- | --- |
| 折痕 | 无爆色、无起毛 | 每 500 册抽 5 册 |
| 抽笺 | 整张抽出无刮边 | 每册抽 3 封 |
| 烫印 | 无虚烫、无偏位（±0.5 mm） | 同上 |
| 编号（漂流本） | 与数字系统清单一一对应、无重号 | **全检**（扫码核验） |
| 附件 | 齐套（笔 / 灯签 ×9 / 贴 ×9 / 帖 ×1） | 每 100 册抽 10 册 |
| 装订 | 锁线牢固，180° 摊开不散 | 每 500 册抽 5 册 |

**编号必须全检**——漂流本编号是数字系统与实体本的唯一对应键，重号会导致九世档案错乱。
