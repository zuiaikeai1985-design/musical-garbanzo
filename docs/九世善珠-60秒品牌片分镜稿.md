## 全片统一规范

- 片长：60 秒整；画幅 16:9（建议 3840×2160 / 24fps）。
- 首帧与末帧：同一张黑底金光莲花标版（含「九世善珠 / guard the love」完整锁定），首尾同构图；标版按 16:9 以纯黑外扩重排，构图不变。
- 全片无字幕、无标语、无价格、无门店、无代言；品牌名只随片尾标版落版（片头标版仅作入口，推镜时字样先沉入黑暗）。
- 视觉：黑棚舞台（黑丝绒吸光背景 + 微反光黑地台）；单一暖橙金光源体系，色温 2200–2600K；道具走暗金锤揲质感（与标版金质同源）；黑位全程死黑。
- 人物：全部东亚真人面孔，年龄与角色严格对应；保留皱纹、毛孔等真实皮肤质感，禁磨皮、禁假脸；表演动作只有：站、走、抬眼、开掌、递、接、颔首、翻经——无跪拜、无仪式表演。
- 核心道具：一串九颗暗金锤揲珠；一册经折装《金刚经》（字迹全程虚焦，不可读）。
- 若以 AI 生成落地：逐段以本表为提示词底稿，锁死「东亚真实面孔／真实皮肤／画面无字」。

## 分镜正文

### 0:00–0:05（5 秒）｜起：标版即世界

- **画面**：第 0 帧即标版——纯黑底，金光莲花居中，莲心光随一次「呼吸」微涨微落；镜头向莲心缓推，「九世善珠」字样随黑暗先行沉没（标版元素退场，非另加字），莲瓣金光放大弥漫，化为有纵深的黑棚空间。
- **人物动作**：无人物。
- **镜头**：固定起幅 2 秒 → 匀速缓推 3 秒，由平面标版推成「一团有体积的光」。
- **光线**：唯一光源是莲心自发光，约 2400K；四周死黑。
- **声音/旁白**：前 1.5 秒全静；第 2 秒一记低沉磬声，余韵拉长；随推进升起极低频铺底。无旁白。
- **叙事作用**：兑现「从 logo 开始」；把商标之光变成故事之光，带观众进入九世。

### 0:05–0:10（5 秒）｜一人

- **画面**：黑棚地面亮起一池直径约两米的暖金圆光，如舞台追光。一名青年男子（28–32 岁）立于光心，手中垂一串暗金锤揲珠——九颗主珠，锤痕与标版金质同源，珠面反着细碎金点，是画面最亮处。
- **人物动作**：低头看珠 → 拇指捻过第一颗珠 → 缓缓抬眼，望向黑暗深处。
- **镜头**：顶光全景（带地台反光）→ 珠串特写（浅景深，锤揲纹理满幅）→ 面部近景（真实皮肤质感）。
- **光线**：单一顶部暖金光柱，光比极大，脸半明半暗；眼神光一粒。
- **声音/旁白**：心跳式大鼓极轻进入（约 52BPM）；捻珠一声细响。无旁白。
- **叙事作用**：立「一个人」；珠是善念的载体，为「传递」备好物证。

### 0:10–0:20（10 秒）｜九世

- **画面**：大俯拍——黑场中九池圆光沿一道缓弧次第点亮，排布恰似一串珠。男子由第一池走向第九池：每入一池，执珠之手与衣着剪影更替一个年代（手由青年到苍老；布衣、长衫、中山装、现代素衣仅以剪影暗示，不做字面朝代），那串珠始终不变。行至第九池，人已是老者（70–75 岁）。
- **人物动作**：匀速行走；每次入光，手先入光、人后入光；第九池驻足，珠贴胸前。
- **镜头**：高位大俯拍（看清「九灯如珠链」）→ 低角度跟走（脚步与光池交替）→ 手部特写九次点切接力（每次约 0.5 秒）→ 老者入第九池正面中景。
- **光线**：九池同为暖金、亮度一致；身前暗、入光亮，行走自带明暗呼吸。
- **声音/旁白**：鼓点与脚步对齐；每入一池一记轻磬泛音，共九记。旁白（男声，60–70 岁，近似诵读，第 13 秒起）：「一切有为法，如梦幻泡影，如露亦如电，应作如是观。」
- **叙事作用**：九盏灯即九世，同一串珠穿过九世，点题「九世传递」；《金刚经》第一句给出看待一生的眼光。

### 0:20–0:30（10 秒）｜一人见三人

- **画面**：第九池光圈缓缓扩大。黑暗边缘浮出三张脸——孩童（6–8 岁）、青年女子（25–28 岁）、中年男子（48–52 岁），面孔先于身体被照见。老者向前半步，开掌，珠串横陈掌心；一缕暖光顺着珠串「流」向对面，三张脸如烛传烛，依次亮起（现场以灯光 cue 渐亮完成，后期只加极轻光尘，不做魔法特效感）。
- **人物动作**：老者开掌、颔首；三人抬眼、受光、各自颔首回礼；孩童下意识伸手，青年女子眼里有泪光但不落，中年男子喉结轻动。全程站立。
- **镜头**：老者开掌的过肩镜 → 横移轨缓扫三张脸（每脸约 1.5 秒，浅景深，睫毛与皮肤质感清晰）→ 四人同框对称中景（老者居左、三人居右，舞台式站位）。
- **光线**：光由「一池」变「一带」；三张脸按序被 2400K 暖光点亮；每人一粒眼神光；黑位不破。
- **声音/旁白**：磬的余韵铺底；对应三张脸亮起，三次极轻的「烛芯点燃」声；心跳鼓略升。无旁白。
- **叙事作用**：完成「一个人见到三个人」；第一次「传」——传的不是物，是光与善念；三个年龄恰是一生三段。

### 0:30–0:40（10 秒）｜三人见很多人

- **画面**：三人各自转身，朝黑暗的三个方向迈出一步；以每人为圆心，身后一圈圈脸被光唤醒——光如水面涟漪层层推开，数十张东亚面孔（7–75 岁，素色深衣）从纯黑中显影。大俯拍：人群站位呈环抱的莲瓣弧线，弧心正是老者与那串珠。
- **人物动作**：众人只做三件事——睁眼抬头、被照亮、向光源缓缓侧身；有人手里攥着自家的旧珠串，材质各异、岁月感各异；节奏参差如呼吸，不做整齐划一。
- **镜头**：轨道横移扫脸（近景）两组；插两枚特写（一双少年的眼、一只攥珠的老手）；收在升格大俯拍（50% 速率，莲瓣状人阵成形）。
- **光线**：程控灯阵做「涟漪波」：光波自三个圆心向外一圈圈传递，波峰 2600K，波谷回落黑；整体亮度只到全片峰值八成，给片尾留头。
- **声音/旁白**：无词人声哼鸣进入（女声起，渐加低声部）；鼓点变密但音量不增；光每推一圈，叠一层轻气息声。无旁白。
- **叙事作用**：完成「三个人见到很多人」；善念扩散被拍成光的涟漪；人阵暗埋「莲花」构图，为回标版设伏。

### 0:40–0:50（10 秒）｜众人走向修行

- **画面**：黑暗最深处升起一团更亮的暖金光源，如未见其形的晨曦（不出现建筑、造像）。众人自发转身，朝光缓行，剪影层层叠叠。前景两组手：一双中年的手翻开经折装《金刚经》，页口金边反光、字迹虚焦不可读；一双苍老的手把那串九珠轻轻放进一双年轻的手里——正是三人中的青年女子。
- **人物动作**：各自速度行走，不列队；翻经；递珠、接珠；老者递珠后停步目送，眼角带笑；女子握紧珠串，继续向光走。
- **镜头**：大逆光全景（人群剪影向光）→ 前景手部特写两组（翻经／递珠）→ 老者停步目送近景（逆光轮廓，侧面补微光）→ 跟拍女子握珠入光的背影。
- **光线**：主光转为纵深逆光，2200K，极薄体积感只为勾金边轮廓；经卷金边与珠串高光与标版金相互呼应。
- **声音/旁白**：哼鸣升至全片情绪顶点后骤然收薄；旁白（同一男声，第 44 秒）：「应无所住，而生其心。」尾音落下，只余脚步与呼吸。
- **叙事作用**：完成「大家走向修行」——修行就是向光走路这件日常事；《金刚经》以实物与经声点题「通过金刚经了解人的一生」；珠的最后一次交接宣告：第九世传向下一世，守护不断代（guard the love）。

### 0:50–1:00（10 秒）｜归一：回到标版

- **画面**：大俯拍中，行走的人群与灯光渐次收拢；每人头顶那点暖光缓缓升离，化作金色光点（人形随黑暗沉没，不见离场动作）；数十粒光点向画面中心汇聚——先聚成一枚锤揲金珠的轮廓，随即自珠心绽开为金光莲花，与片头同一朵。镜头持续后拉回正，「九世善珠 / guard the love」自莲下缓缓浮现，落成与第 0 秒完全同构图的标版，定帧至 60 秒整。
- **人物动作**：无（人物已化入光点）。
- **镜头**：一镜完成「人群 → 光点 → 金珠 → 莲花 → 标版」的连续后拉 + 缓慢下摇，速度曲线与片头推镜互为镜像。
- **光线**：光点汇聚瞬间达到全片亮度峰值，随即回落为标版的稳定莲光；黑位始终死黑。
- **声音/旁白**：第 52 秒哼鸣与鼓全部收掉；第 54 秒最后一记磬（与片头同一采样，余韵更长）；第 57–60 秒只余磬尾与一次轻轻的吸气、呼气。无旁白，不口播品牌名。
- **叙事作用**：兑现「第 60 秒回到同一张 logo、首尾同构图」；所有人的善念汇成这朵莲——落版时，logo 已不是商标，而是整支片子的总和。

## 旁白汇总（全片仅两句，均出自《金刚经》原文）

- 13–19 秒：「一切有为法，如梦幻泡影，如露亦如电，应作如是观。」
- 44–47 秒：「应无所住，而生其心。」
- 声线：男声 60–70 岁，诵读感，不带广告腔；干声为主，混响极浅。

## 声音结构

静 → 磬（2 秒）→ 心跳鼓（5 秒起）→ 九记磬泛音（10–20 秒）→ 烛芯点燃 ×3（20–30 秒）→ 无词哼鸣（30 秒起）→ 顶点收薄 + 经声（40–50 秒）→ 末磬（54 秒）→ 静（57–60 秒）。全片以「磬」为唯一贯穿主奏，避免配乐广告感。
