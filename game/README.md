# OPERATION: DUST — 浏览器 FPS

一个用 Three.js + TypeScript 写的类 CS 第一人称射击游戏，全部资源（贴图、模型、音效）都在运行时程序化生成，不依赖任何外部素材。

## 运行

```bash
cd game
npm install
npm run dev      # http://localhost:5173
```

其他命令：

```bash
npm run build      # 类型检查 + 生产构建到 game/dist
npm run preview    # 预览构建产物
npm run typecheck  # 只做类型检查
```

## 玩法

- 一波一波的敌人 AI，从地图各处的出生点向你推进；清光一波即进入下一回合。
- 每回合敌人数量递增，回合结束会回复生命并补满弹药。
- 被击杀即结算，显示坚持回合数、击杀、爆头、命中率与总伤害。
- 难度分为新兵 / 士兵 / 特种兵，影响 AI 反应时间、精度、伤害与出场数量。

## 武器

| 武器 | 类型 | 伤害 | 弹匣 | 特点 |
| --- | --- | --- | --- | --- |
| AR-47 | 全自动步枪 | 33 | 30 | 固定弹道的后坐力，压枪可控 |
| MP-5K | 冲锋枪 | 24 | 30 | 射速快、移动精度高、伤害低 |
| P-9 | 半自动手枪 | 27 | 12 | 移动最快，爆头四倍伤害 |
| AWM-S | 栓动狙击枪 | 118 | 5 | 开镜命中躯干基本一枪 |
| 军刀 | 近战 | 55 | ∞ | 背刺 200 伤害，秒杀 |

命中部位有倍率：头部（步枪 ×4）、腹部 ×1.15、腿部 ×0.75，并带有距离衰减与护甲穿透计算。

## 实现要点

- **命中判定**：自己实现的射线-AABB 求交，敌人分头/胸/腹/腿四个命中盒，不走 Three.js 的 mesh raycast，性能更稳定也更好调。
- **移动手感**：Quake/CS 系的加速度 + 摩擦力模型，空中加速度受限，可以做出空中转向；蹲下会即时改变碰撞盒高度与视点高度。
- **后坐力**：每把枪有一组喷射弹道（spray pattern），连发时按序应用，配合准星动态张开，练熟了可以压枪。
- **AI**：视野检测（射线遮挡 + 视野角）→ 反应延迟 → 点射/走位；丢失目标后会去最后已知位置搜索并转移到掩体点。
